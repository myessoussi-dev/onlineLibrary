1) 🔌 @Autowired vs Injection par constructeur

👉 @Autowired
- Sert à injecter une dépendance automatiquement
- Exemple :
  @Autowired
  private BookService bookService;

⚠️ MAIS :
- aujourd’hui on évite ça dans le code moderne

👉 Pourquoi ?

✔ injection par constructeur est meilleure :

public class BookController {
    private final BookService bookService;

    public BookController(BookService bookService) {
        this.bookService = bookService;
    }
}

👉 Avantages :
- immutabilité (final)
- test plus facile (unit tests)
- code plus propre
- recommandé par Spring (best practice)

📌 Conclusion :
👉 @Autowired = ancien style
👉 constructeur = style pro moderne

------------------------------------------------

2) 📦 DTO (Data Transfer Object)

👉 C’est quoi ?
Un objet utilisé pour transférer les données entre :
- backend ↔ frontend
- API ↔ client

❌ On ne renvoie pas directement l’Entity
✔ On utilise un DTO

Ex :
Entity Book :
- id
- title
- internal fields (DB, relations, etc.)

DTO BookDTO :
- title
- authorName
- categoryName

👉 Pourquoi DTO ?

✔ sécurité (on cache les champs sensibles)
✔ contrôle des données envoyées
✔ éviter de casser la DB structure côté API
✔ meilleure séparation des responsabilités

📌 Conclusion :
Entity = base de données
DTO = API / communication

------------------------------------------------

3) ⚡ Lambda functions (Java)

👉 C’est quoi ?
Une façon courte d’écrire des fonctions

Ex classique :
books.stream()
     .filter(b -> b.getTitle().contains("Java"))
     .toList();

👉 Ici :
b -> b.getTitle().contains("Java")
= fonction lambda

------------------------------------------------

📌 Pourquoi on utilise les lambdas ?

✔ code plus court
✔ plus lisible
✔ base de Stream API
✔ permet le traitement fonctionnel des collections

------------------------------------------------

4) 🔥 Stream API (lié aux lambdas)

Ex :
List<Book> result = books.stream()
    .filter(b -> b.getAuthor().equals("Victor Hugo"))
    .toList();

👉 opérations possibles :
- filter() → filtrer
- map() → transformer
- sorted() → trier
- collect() → convertir en liste
